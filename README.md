# QuickTools

A responsive, static website containing 12 browser-based utilities. Built with plain HTML, CSS and JavaScript; no build step or paid service is required to run it locally.

## Included tools

1. Word Counter
2. Case Converter
3. Remove Extra Spaces
4. Slug Generator
5. Text Reverser
6. Line Sorter
7. JSON Formatter
8. URL Encoder / Decoder
9. Base64 Converter
10. Password Generator
11. UUID Generator
12. Lorem Ipsum Generator

## Run locally

Open `index.html` in a modern browser. For best results, serve the folder with any static local server. No package installation is required.

## Before publishing

1. Replace every `YOUR-DOMAIN.com` placeholder in `index.html`, `robots.txt` and `sitemap.xml` with your final domain.
2. Replace `YOUR-CONTACT-EMAIL@example.com` in `contact.html` with an email address you control.
3. Review and customize the Privacy Policy, Terms and Disclaimer to match your actual hosting, analytics, ad network, cookies, consent mechanism and legal requirements. The included legal pages are starter templates, not legal advice.
4. The ad placeholder in `index.html` is not an active advertisement. After your Adsterra account and site are approved, insert the exact ad code supplied by Adsterra in the marked ad area. Review the provider's current policies and any applicable consent requirements first.
5. Test all tools and pages on mobile and desktop after deployment.
6. Submit your sitemap in Google Search Console after the site is live. A sitemap does not guarantee indexing or rankings.

## Free static hosting options

You can deploy this folder using a static hosting provider's free tier, subject to its current limits and terms. Examples include GitHub Pages, Cloudflare Pages and Netlify. You will still need to check domain availability and the host's current pricing/limits; a custom domain may cost money.

## Notes

- The tool logic runs client-side in the visitor's browser.
- Google Fonts is loaded from Google Fonts; remove the `@import` in `styles.css` if you prefer no external font request.
- This starter project does not include an active analytics system, ad script, cookie banner, backend, user accounts or a custom domain.
