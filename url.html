What is URL encoding?

URL encoding, also called percent encoding, is a method of representing certain characters in a URL using a percent sign followed by hexadecimal values. It helps represent characters that have special meanings or cannot be used directly in certain parts of a URL.

For example, a space can be represented as %20 in a URL component.

What is a URL Decoder?

URL decoding reverses percent encoding. It converts encoded characters back into their original readable form. This is useful when inspecting encoded links, query strings or data received from web applications.

URL encoding example

Here is a simple example:

Original text: Hello World!

Encoded text: Hello%20World!

Decoding the encoded text returns the original readable text. The exact output depends on the characters and the encoding method used.

URL encoding tips

  • Use URL encoding for the appropriate URL component, not blindly for an entire URL.
  • Do not encode the same text repeatedly unless that is specifically required.
  • Remember that spaces may be represented differently in URL query form data.
  • Check decoded text before using it in an application.

Frequently Asked Questions

What does percent encoding mean?

Percent encoding represents certain characters using a percent sign followed by hexadecimal digits. It is commonly used when preparing data for URLs.

What does %20 mean in a URL?

In a URL component, %20 represents a space character.

Can I decode an encoded URL?

Yes. Paste percent-encoded text into the tool and select the decode option to convert it into readable text.

Is URL encoding the same as encryption?

No. URL encoding is a text representation method, not a security feature. It does not protect confidential information or hide data from people who can access it.
